## 教学说明

**学习目标**

1. 能按顺序说出 NLP 发展的四个阶段及代表性事件（记忆）；
2. 能说出每个阶段“人做什么、机器做什么”（理解）；
3. 能用同一个例子解释规则方法为什么处理不好否定（分析）。

**画面与操作**

- 上方四张卡片是四个时代，中间时间轴上的圆点是大事件，点击即可查看。
- 下方卡片列出这个时代的思路、优点和局限，并提供一个“判断情绪”的小实验，可以改写句子再试。

**数据来源**：大事件取自教材 1.2 节。小实验中的“统计”和“深度学习”结果是按各自思路编写的简化演示，不是真实模型的输出。

**课堂用法建议**

1. 先让学生猜：规则方法会怎样判断“我一点也不难过”？再点开验证，联系 1.2.1 节的 ELIZA 代码。
2. 让学生自己写一句“规则方法判断错、大模型判断对”的句子，说明原因。
