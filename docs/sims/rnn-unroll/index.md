## 教学说明

**学习目标**

1. 能说出 RNN 每一步用到的输入（当前词和上一步的隐藏状态）（记忆）；
2. 能解释“参数共享”与“循环”的含义（理解）；
3. 能用连乘解释梯度消失，以及它对长句的影响（分析）。

**画面与操作**

- 上方：按时间展开的 RNN，每个方框里的三根柱子是隐藏状态的三个维度（红：情感，蓝：在说配送，紫：语气强度）。
- 中间：当前一步的计算过程。下方：每个词对最终结果的影响（梯度，按对数画出）。

**数据来源**：为了看清原理，隐藏状态只有 3 维，词向量由编者手工设定（没列出的词按中性词处理），W 和 u 都是对角矩阵。

**课堂用法建议**

1. 读第二个例句，让学生观察“难吃”对应的红柱怎样一步步缩短，讨论分类层为什么判断不出负面。
2. 把 u 调到 0.95 再读一遍，联系 8.5 节 LSTM 的“记忆细胞”。
