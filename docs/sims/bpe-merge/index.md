## 教学说明

**学习目标**

1. 能描述 BPE 每一步“统计—合并”的过程（理解）；
2. 能根据片段对的次数预测下一次合并（应用）；
3. 能解释 BPE 为什么能让常见词完整、罕见词拆成子词（分析）。

**画面与操作**

- 左上：语料现在被切成的片段，黄色是刚合并出的新片段。右上：相邻片段对的出现次数，黄色行是下一次要合并的。
- 下方是合并记录（BPE 学到的规则）和当前词表，以及整份语料需要的 token 数。

**数据来源**：默认语料与教材 3.6.2 节完全相同，前 4 次合并（es、est、lo、low）与教材一致；次数相同时取先出现的一对。

**课堂用法建议**

1. 让学生先手算第 1 次合并，再点按钮验证。
2. 换成“中文词”语料，观察“语言”“模型”是怎样被合并出来的，联系 3.6.4 节 token 数量。
