## 教学说明

**学习目标**

1. 能描述贪心搜索与束搜索的区别（理解）；
2. 能计算候选序列的整句概率（应用）；
3. 能解释“每步最优不等于整句最优”（分析）。

**画面与操作**

- 左边是“今天天气”，向右每一列是一步扩展出的候选。蓝色是保留的候选，灰色是被剪掉的。
- 方框里是这个词的条件概率，括号里是整句到这里的概率。

**数据来源**：候选词和概率由编者设定，第一步的概率（很 0.35、真 0.20、不 0.15）取自 10.6.2 节的流程图。

**课堂用法建议**

1. 让学生先手算贪心搜索的结果和整句概率，再用动画核对。
2. 讨论：束宽越大越好吗？代价是什么？为什么开放式写作不常用束搜索？
