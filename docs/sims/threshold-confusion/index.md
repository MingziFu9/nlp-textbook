## 教学说明

**学习目标**

1. 能说出阈值变化时，TP、FN、FP、TN 四个格子的数字怎样移动（理解）；
2. 能根据“差评预警”“统计好评率”等业务需求选择合适的阈值（应用）；
3. 能解释精确率和召回率为什么“此消彼长”（分析）。

**画面与操作**

- 左侧直方图：横轴是逻辑回归给出的“好评概率”，红色是实际差评、绿色是实际好评。竖线就是阈值，可以直接拖动，也可以用下方滑块或场景按钮调整。
- 右侧：以“差评”为正类的混淆矩阵，以及准确率、差评的精确率 / 召回率 / F1、好评的召回率。
- 底部：离阈值最近的 5 条评论，拖动阈值时可以看到它们的判断怎样翻转。

**数据来源**：实验 6-2 中逻辑回归对测试集 2398 条外卖评论的实际预测概率。阈值取 0.3、0.4、0.5、0.6、0.7 时，页面上的指标与教材 6.4.6 节的表格完全一致。

**课堂用法建议**

1. 先让学生预测：“把阈值从 0.5 调到 0.7，差评的召回率会升高还是降低？”再拖动验证；
2. 让学生找出准确率最高的阈值，再讨论“准确率最高是不是就最好”；
3. 观察底部的评论，找一条“标签可能标错了”的例子，联系 6.4.9 节错误分析。
