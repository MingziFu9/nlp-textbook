## 教学说明

**学习目标**

1. 能说出否定词和程度副词在词典法中的作用（理解）；
2. 能手工算出一条评论的情感得分（应用）；
3. 能举例说明词典覆盖面和分词结果对词典法的影响（分析）。

**画面与操作**

- 输入一条评论，或点击示例。点“下一步”，每次处理一个情感词：虚线框标出它前面的 3 个词，下方列出这一步的计算过程和累计得分。
- 展开“查看 / 修改情感词典”，可以把新词加入正面词或负面词，马上看到结果变化。

**与实验 6-1 的区别**：网页中没有 jieba，用“词典最长匹配”切词，个别评论的结果会与实验 6-1 不同（页面底部有说明）。这本身就是一个很好的讨论点：分词结果会直接影响词典法的效果。

**课堂用法建议**

1. 先让学生手工算“不好吃，而且送得非常慢”的得分，再点“下一步”核对；
2. 试一试“包装没有破损，饭菜也没凉”：为什么得分和实验 6-1 不一样？把“破损”加入负面词后又会怎样？
3. 让学生自己写一条“词典法一定会判错”的评论（提示：反讽、隐式情感），联系 6.5.4 节。
