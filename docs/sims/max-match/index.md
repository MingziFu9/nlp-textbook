## 教学说明

**学习目标**

1. 能复述正向和逆向最大匹配的步骤（记忆）；
2. 能说出双向最大匹配选择结果的规则（理解）；
3. 能通过增删词典中的词，解释最大匹配法对词典的依赖（分析）。

**画面与操作**

- 句子中的每个字是一个方块，橙色是正在查词典的片段，绿色是已切出的词。
- 下方日志记录每一次“查到 / 查不到”。“三种方法对比”给出双向匹配的选择理由。
- 展开“词典”可以点词删除，或输入新词加入。

**数据来源**：词典与实验 3-1 的代码完全相同，“研究生命的起源”的逐步过程与 3.3.1 节两张表格一致。

**课堂用法建议**

1. 让学生先在纸上按 3.3.1 节的表格推演，再用动画核对。
2. 完成实验 3-1 思考题：删去“卖完”“南京市”后，结果怎样变化？
