# 自然语言处理导论

**课程名称：** 自然语言处理导论

**授课对象：** 成人教育（继续教育）人工智能技术应用专业专科学生，多为在职学习者

**学分学时：** 4 学分，72 学时（理论 60 学时，实验 12 学时）

**先修要求：** 具备计算机基础操作能力；学过或同步学习“Python 程序设计基础”（会写变量、循环、函数，会安装第三方库）。不要求高等数学基础，涉及的数学概念（概率、向量）在书中用生活化例子讲清。

## 课程概述

自然语言处理（NLP）是让计算机“听懂、看懂、会写”人类语言的技术，是智能客服、搜索引擎、机器翻译、语音助手以及 ChatGPT、文心一言、通义千问、DeepSeek 等大语言模型背后的核心技术。对于人工智能技术应用专业的专科学生而言，NLP 是将来从事 AI 训练师、数据标注与处理、智能客服运维、AI 应用开发等岗位的必备知识。

本课程坚持“够用、能用、会用”的原则：理论讲到能理解原理为止，不做复杂公式推导；每一章都配有可在普通笔记本电脑或免费在线环境（如 Google Colab、阿里云天池、百度 AI Studio）中完成的动手实验。课程从文本处理基础讲起，逐步过渡到传统机器学习方法、深度学习方法、预训练模型和大语言模型，最终完成一个综合性的智能问答小项目。

学完本课程，学生能够看懂 NLP 项目的基本流程，能用 Python 和常用工具库完成分词、文本分类、情感分析、信息抽取等常见任务，并能借助大模型 API 搭建简单的 NLP 应用。

## 主要内容

- 自然语言处理的概念、发展历史与典型应用
- Python 文本处理基础：字符串、编码、正则表达式、数据清洗
- 词法分析：中英文分词、词性标注、词干提取与词形还原（NLTK、spaCy、jieba）
- 句法分析：成分句法与依存句法
- 文本表示：独热编码、词袋模型、TF-IDF、文本相似度
- 词向量：分布式表示、Word2Vec、语义相似度
- 文本分类：朴素贝叶斯、逻辑回归、模型评价指标
- 情感分析：基于词典与基于机器学习的方法
- 机器翻译与文本生成：Seq2Seq、神经机器翻译、BLEU 评价
- 信息抽取：命名实体识别、关系抽取、关键词与摘要
- 深度学习与 NLP：神经网络、RNN/LSTM 基础
- Transformer、注意力机制与预训练模型（BERT、GPT）
- 大语言模型与提示词工程（Prompt Engineering）
- 智能问答与对话系统、检索增强生成（RAG）
- NLP 中的伦理、隐私与法律问题，语言数据处理的最佳实践

## 不涉及的内容

- 复杂数学推导（反向传播公式推导、概率图模型推导等）
- 语音识别与语音合成的信号处理细节
- 从零训练大语言模型、分布式训练与模型压缩
- 形式语言与自动机理论、句法分析算法的形式化推导
- 学术前沿论文研读

## 学习目标

完成本课程后，学生能够：

### 记忆（Remember）
- 说出自然语言处理的定义及 5 种以上典型应用场景
- 列举中文 NLP 的常用工具与库（jieba、scikit-learn、gensim、Hugging Face Transformers 等）
- 复述分词、词性、停用词、语料库、词向量等基本术语
- 列出文本分类的常用评价指标（准确率、精确率、召回率、F1 值）
- 识别 RNN、LSTM、Transformer、BERT、GPT 等模型名称及其所属阶段

### 理解（Understand）
- 用自己的话解释中文分词为什么比英文分词更难
- 解释词袋模型与 TF-IDF 的思路及其局限
- 说明词向量如何让“意思相近的词距离更近”
- 解释注意力机制的直观含义与预训练+微调的思想
- 说明大语言模型的工作方式（预测下一个词）及“幻觉”现象的成因

### 应用（Apply）
- 使用正则表达式和 Python 完成文本清洗
- 使用 jieba 完成分词、词性标注、自定义词典与关键词提取
- 使用 scikit-learn 构建 TF-IDF + 分类器的文本分类流程
- 使用 Hugging Face pipeline 调用预训练模型完成情感分析与实体识别
- 调用国产大模型 API 并编写有效的提示词完成指定任务

### 分析（Analyze）
- 分析一个 NLP 任务的输入、输出与处理流程
- 通过混淆矩阵分析分类模型出错的原因
- 比较规则方法、机器学习方法与深度学习方法的优缺点
- 分析数据质量（噪声、类别不平衡）对模型效果的影响

### 评价（Evaluate）
- 根据评价指标选择更合适的文本分类模型
- 判断大模型输出内容的准确性与可靠性
- 针对具体业务场景评估应选用传统方法还是大模型
- 评估 NLP 应用中的隐私、偏见与合规风险

### 创造（Create）
- 设计并实现一个电商评论情感分析小工具
- 为一个具体场景设计一组提示词模板
- 综合项目：基于 RAG 搭建一个面向特定领域（如校园、企业制度、产品说明）的智能问答助手，并撰写项目报告
